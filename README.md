# BidDeed.AI Web

Next.js App Router skeleton for BidDeed.AI — Auction Intelligence.

## Stack

Next 16 (webpack build), React 18, TypeScript, Tailwind CSS.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Status

Phase 1a scaffold — skeleton only. No data, no components ported, no auth, no deploy.

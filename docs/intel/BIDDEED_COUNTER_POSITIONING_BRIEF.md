## 1. Positioning thesis

### The load-bearing distinction

| | Market-dashboard SaaS (Reventure archetype) | BidDeed.AI |
|---|---|---|
| Category frame | Vertical proptech analytics app — ZIP/metro KPIs + 12-month forecast | **Agentic AI ecosystem** for distressed-auction operators — agent (Deed) + domain skills across discover → price → zone → drive → rehab |
| Unit of value | “Is this **ZIP / metro** going up or down?” | “What is the ceiling on **this parcel**, in **this county**, at **this auction**, with the **exit modelled**?” |
| Hero surface | Home Price Forecast + Overvalued % | SIGNAL$ Max Bid + live county calendar + outcome scorecard |
| Cadence | Monthly market refresh | Event-time dockets (upcoming sales / this week / this month) |
| Valuation story | SaaS ARR on dashboard seats | Agentic usage + domain-skill moat (auction intelligence, not chat chrome) |

**One-sentence thesis (use everywhere):**  
Reventure-class tools sell national **macro dashboards**. BidDeed sells the **specific distressed property** — this county, this auction, this ceiling, this exit — through an **agentic AI ecosystem**, not another SaaS spreadsheet with a map.

### Why “agentic ecosystem, not SaaS” is load-bearing

- **SaaS framing** peers BidDeed with dashboard tools (Reventure, listing analysers, ZIP forecast apps). Wrong peer set → wrong price ceiling → wrong investor narrative. **INFERRED** from G1 contrast + category directive.
- **Agentic ecosystem framing** peers BidDeed with products where the user (or their agent) states a **goal** and the system runs **tools** against proprietary domain data — calendar → record → max bid → zoning → field route → rehab math — with answers that cite the record. **INFERRED** as category language; public surface already shows Deed as agent plus multi-skill workflow. **VERIFIED** agent label and skill surfaces: [https://biddeed.ai](https://biddeed.ai).
- **Do not claim** a public third-party tool marketplace / open agent protocol as live customer-facing product until it ships and is shown on biddeed.ai. That remains **UNTESTED / roadmap** — see `G2_STATUS.md` for Ariel approval before elevating in external decks.

### Contrast that must land in five seconds

| They sell | We sell |
|---|---|
| ZIP home-price forecast | Parcel max bid before the sale |
| Inventory / DOM / overvaluation % | County auction calendar + judgment / plaintiff / comps |
| “Where is the market going?” | “What do I bid on *this lot*, and what survives the sale?” |
| Monthly macro refresh | Published before the sale; checked after it |
| YouTube crash narrative → app upgrade | Talk to Deed → act on a specific auction |

**VERIFIED Reventure side (G1):** Free $0 / Premium **$39/mo** / **$399/yr**; 8 free points / 40+ premium; forecasts for ~30,000 ZIPs; **not** parcel-level foreclosure/auction workflow. Sources: [https://www.reventure.app/](https://www.reventure.app/), [https://www.reventure.app/pricing](https://www.reventure.app/pricing), G1 teardown.  
**VERIFIED BidDeed side:** Foreclosure & tax deed auctions; Deed agent; SIGNAL$ Max Bid; 67 Florida counties; Free → Investor $99 → Pro $199 → Pro Plus $399; ZoneWise zoning; D4D routes; Projects rehab. Sources: [https://biddeed.ai](https://biddeed.ai), [https://biddeed.ai/pricing](https://biddeed.ai/pricing), [https://zonewise.ai](https://zonewise.ai).

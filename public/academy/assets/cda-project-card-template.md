# Member Project Card Template

One card per project. Same skeleton every time. Six real cards beat ten fake ones.

| Field | Rule |
|---|---|
| Photo | Real photo of the real project |
| Product type | Duplex / ADU / small MF / mixed-use etc. |
| Stage pill | Under contract / Entitled / Under construction / Leasing-sold / Stabilized / Founder |
| Name | Project or operator name |
| One-liner | One sentence, plain |
| Specs | Units, sqft, lot |
| One number | ONE number only (basis, rent, or sale price) |
| Stack | Capital stack in one line |
| Status | Where it stands today |
| Attribution | Who owns it, linkable |

## Banned numbers

- Projected IRR
- "$50k/month" income claims
- Bonus-value math

## Suggested mix (10 cards)

- 2 founder projects
- 2 under contract
- 2 permitted / entitled
- 2 under construction
- 2 leased or sold
